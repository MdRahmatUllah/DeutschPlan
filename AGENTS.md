# For coding agents

Start with [`CLAUDE.md`](CLAUDE.md): the overview, the session ritual and the
rules. The full guide is [`ONBOARDING.md`](ONBOARDING.md). Coordination (the
task file, status, plan, project and per-agent memory) lives on the `team`
branch and is changed only through `python tools/team.py`.

On a new device, or taking an identity for the first time, read
[`developer-agents/README.md`](developer-agents/README.md): the team, the setup,
each agent's role and memory, and how to restore the memory.
