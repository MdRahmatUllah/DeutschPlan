DeutschPlan V2 — Aurora Glass design files (HTML)

index.html                 links to the four canvases
android-light/index.html   every Android light-mode artboard on one page, laid out like the canvas
android-light/screens/     one standalone HTML file per screen; buttons and tab bars link between screens (clickable prototype)
android-dark/, ios-light/, ios-dark/   the same for the other three canvases

Foundations.html in each screens/ folder is the token and component sheet for that theme.
Open any file directly in a browser. Fonts (Inter, Noto Sans Bengali) load from Google Fonts when online.
